HANDSHAKE PROTOCOL
==================

The handshake establishes authentication and provides hardware configuration
to the client before normal operations can begin.

Flow:
1. Client connects via TCP
2. Server sends hardware summary
3. Client responds with authentication token
4. Server validates and confirms


STEP 1: SERVER -> CLIENT (Initial Handshake)
--------------------------------------------
Source: fireq_server.py  _build_handshake_info()

{
  "type": "handshake",
  "protocol_version": "0.3.0",
  "hw_summary": {                              // FIREQSoC.summary()
    "bitfile":           str,                  // e.g. "fireq_v3.bit"
    "num_generators":    int,
    "num_acquisitions":  int,
    "num_triggers":      int,
    "has_dma":           bool,
    "has_axis_switch":   bool,
    "has_rf":            bool,
    "hw_specs":          { ... }               // see FULL hw_specs STRUCTURE below
  }
}


STEP 2: CLIENT -> SERVER (Authentication)
-----------------------------------------
{
  "type": "handshake_ack",
  "token": "fireq",                            // Authentication token (default: "fireq")
  "client_name": "Lab_Control_PC"
}


STEP 3: SERVER -> CLIENT (Confirmation)
---------------------------------------
On success:
{
  "type": "handshake_ok",
  "message": "Welcome Lab_Control_PC"
}

On failure:
{
  "type": "handshake_error",
  "error": "Invalid token"
}


================================================================================
FULL hw_specs STRUCTURE
================================================================================
Source: fireq_soc.py  _build_hw_specs()

hw_specs has 5 top-level keys: "rf", "acquisitions", "generators", "triggers",
"summary".


hw_specs["rf"]
--------------
RF Data-Converter tile information. DAC/ADC clocks must be synchronous across
all tiles (multi-tile sync); a mismatch raises RuntimeError.

{
  "dac_sr_hz":      float,                     // DAC sample rate (Hz)
  "adc_sr_hz":      float,                     // ADC sample rate (Hz)
  "dac_nyquist_hz": float,                     // dac_sr_hz / 2
  "adc_nyquist_hz": float,                     // adc_sr_hz / 2
  "dac_tiles": [                               // one entry per active DAC tile
    {
      "tile":           int,                   // tile index
      "sample_rate_hz": float,
      "pll_lock":       str                    // e.g. "1" or "Unknown"
    }
  ],
  "adc_tiles": [                               // one entry per active ADC tile
    {
      "tile":           int,
      "sample_rate_hz": float,
      "pll_lock":       str
    }
  ]
}


hw_specs["acquisitions"]
------------------------
List, one dict per AcquisitionDriver (acquisition IP).

[
  {
    "index":                      int,
    "sample_bits":                int | null,
    "parallelism":                int | null,
    "phase_bits":                 int | null,
    "trigger_word_width":         int | null,
    "duration_bits":              int | null,
    "max_duration_cycles":        int | null,
    "time_of_flight_bits":        int | null,
    "time_of_flight_max":         int | null,
    "raw_output_width_bits":      int | null,
    "dec_output_width_bits":      int | null,
    "raw_fifo_depth_words":       int | null,
    "decimated_fifo_depth_words": int | null
  }
]


hw_specs["generators"]
----------------------
List, one dict per GeneratorDriver (generator IP).

[
  {
    "index":                              int,
    "sample_bits":                        int | null,
    "parallelism":                        int | null,
    "phase_bits":                         int | null,
    "trigger_word_width":                 int | null,
    "duration_bits":                      int | null,
    "max_duration_samples":               int | null,
    "sample_mem_addr_bits":               int | null,
    "sample_mem_depth_words_per_channel": int | null,
    "fractional_precision_bits":          int | null,
    "wave_memory_depth":                  int | null,
    "mm_fifo_depth":                      int | null,
    "axi_full_depth_bytes":               int | null,
    "total_sample_mem_segment_depth":     int | null,
    "lfsr_seed_bits":                     int | null
  }
]


hw_specs["triggers"]
--------------------
List, one dict per TriggerGeneratorDriver (trigger IP).

[
  {
    "index":                          int,
    "trigger_channels":               int | null,
    "fifo_interface_mem_depth_bytes": int | null,
    "channel_fifo_depth_words":       int | null,
    "fifo_output_width_bits":         int | null,
    "drive_delay_max":                int | null,
    "experiment_timer_max":           int | null,
    "max_hw_repetitions":             int | null
  }
]


hw_specs["summary"]
-------------------
Convenient global aggregates. Values marked "uniform only" are set only when
all IPs share the same value; otherwise null.

{
  "dac_sr_hz":                float,
  "adc_sr_hz":                float,
  "dac_nyquist_hz":           float,
  "adc_nyquist_hz":           float,
  "adc_parallelism_set":      [int, ...],      // sorted unique values across acq IPs
  "dac_parallelism_set":      [int, ...],      // sorted unique values across gen IPs
  "adc_parallelism":          int | null,      // uniform only
  "dac_parallelism":          int | null,      // uniform only
  "trigger_channels_set":     [int, ...],      // sorted unique values across trig IPs
  "trigger_channels":         int | null,      // uniform only
  "max_hw_repetitions_min":   int | null,      // min across all trigger IPs
  "experiment_timer_max_min": int | null       // min across all trigger IPs
}


NOTES
-----
- Handshake must complete within 3 seconds (HANDSHAKE_TIMEOUT_SECONDS = 3.0)
- After successful handshake, the client can send commands
- hw_specs content depends on the actual hardware configuration; fields read
  via getattr default to null when the IP driver does not expose the attribute
- Differences in parallelism / memory sizes across IPs are accepted and
  reflected per-IP in the lists; only DAC/ADC clock rates must be uniform
